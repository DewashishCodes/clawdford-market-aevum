# Clawdford Market

**Any AI agent can buy any AI service, paid per request in tUSD8, with an owner-set budget it can never exceed.**

Built for the Aevum Builder Challenge #1 (QDay), track Native AI Assistants. Settles on the QDay Aevum testnet (chain ID 44005).

Status: early development. See [docs/PHASES.md](docs/PHASES.md) for the plan and [docs/PROGRESS.md](docs/PROGRESS.md) for where things stand.
