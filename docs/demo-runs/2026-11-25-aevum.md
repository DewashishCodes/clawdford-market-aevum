# Run on Aevum testnet, Nov 25 2026

Every PRD workflow run on QDay Aevum (chain 44005) with real tUSD8. Facilitator and sellers ran locally against the public RPC (`https://rpc-test.qday.info`); the stalls' endpoints and agent cards point at `http://127.0.0.1:4030` until they are hosted (both can be updated on chain with `updateStall` and `IdentityRegistry.update`). The agent was the MCP server, driven tool by tool with `MCP_CONFIG=aevum-mcp-1.json pnpm call-tool ...`; the owner used `pnpm owner ...` (`mcp/scripts/owner.ts`), which makes the same calls as the web owner console. LLM stalls used Groq (`qwen/qwen3.8-27b`).

Explorer: `https://explorer-test.qday.info/tx/<hash>`. Contracts are in the README and `deployments/44005.json`.
